# 팀 보고 — 이종민 담당 화면 (SCR-06 · SCR-08 · SCR-13)

2026-11-08 작성 · 기준 문서: 화면별 상세 기능정의서 v2.5 · 자세한 내용: `docs/scr06-08-13.md`

## 1. 한 줄 요약
관찰 게시물 상세, 나의 수족관, 해양 뉴스·칼럼 세 화면을 기능정의서에 맞춰 만들었다. 화면 코드와 DB 코드를 나눴고 자동 시험 52건이 통과한다. 3개 화면 모두 브라우저에서 열어 동작을 확인했다.

## 2. 화면별 현황

| 화면 | 되는 것 | 남은 것 |
| --- | --- | --- |
| SCR-06 관찰 게시물 상세 | 위치 공개 규칙(비공개·대략·정확), 사진 공개 동의 검사, 공감(1인 1회), 댓글·답글, 신고와 임시 숨김(3건), 운영자 검토, 수정·삭제, 돌아가기 | 좌표 입력칸은 SCR-04 담당. 좌표가 없으면 지역 중심점을 쓴다 |
| SCR-08 나의 수족관 | 글이 저장되면 자동 등록(트리거), 새 종은 수집 종 수 증가, 미확인 등록과 이름 바꾸기, 글을 지워도 도감 기록 유지, 표 보기(사진·이름·사용자·관찰됨·장소·업로드 날짜)와 카드 보기, 어항(관찰 5건마다 가득 참) | 도감 상세는 SCR-09 담당. 담당 화면이 들어오기 전까지 임시 화면을 쓴다 |
| SCR-13 해양 뉴스·칼럼 | 많이 읽은 소식 Top 5(최근 30일·1시간 갱신), 목록·검색·기간 필터(기본 3개월), 상세 팝업, 조회수 24시간 1회, 매일 06:00 수집 스크립트, 요약(Gemini 또는 원문 발췌), 운영자 도구 | 실제 뉴스 출처 주소 점검과 06:00 스케줄러 등록은 인터넷이 되는 PC에서 해야 한다 |

## 3. 보여 줄 순서 (데모)
1. 화면 왼쪽 아래 "화면 권한 미리보기"에서 **회원 데모**를 고른다.
2. 커뮤니티 → 글 카드의 "자세히 보기"로 SCR-06을 연다. 댓글을 쓰고 신고 메뉴를 보여 준다.
3. 나의 수족관에서 어항과 표를 보여 준다. 표 행을 선택하면 도감 상세로 간다.
4. 해양 뉴스에서 Top 5, 기간 필터, 상세 팝업을 보여 준다.

## 4. 팀 합의가 필요한 것
- **어항 기능**은 기능정의서에 없는 추가 기능이다. 게임·퀴즈 화면과 겹칠 수 있어 넣을지 정해야 한다.
- **공유 파일 2개**(`streamlit_app.py`, `sea_info/screens.py`)를 고쳤다. 다른 사람이 같은 줄을 고쳤다면 합칠 때 충돌한다. 고친 곳은 인수서 4장에 있다.
- **올리는 방식**: 공동 저장소에 직접 올릴지, 복사본에서 합쳐 달라고 요청할지 정한다.
- **도감 목록(수십~수백 종)**은 SCR-09 담당이 정한다. 지금 12종은 시험용이다.
- **API 키**는 채팅에 올리지 않고 `.env`로 전달하며, 저장소에는 `.gitignore`와 `.env.example`을 둔다.

## 5. 알려진 한계
- 실제 뉴스 출처 주소와 Gemini 호출은 이 개발 환경에서 인터넷이 막혀 시험하지 못했다. 가짜 응답으로 수집·요약·실패 처리를 시험했다.
- 비회원 조회수의 24시간 중복 제외는 접속 정보로 구분하는 근사치이다.
- FastAPI로 옮기는 일은 아직 하지 않았다. 데이터 함수(`*_store.py`)를 엔드포인트 본문으로 쓸 수 있게 나눠 두었다.
- "관찰됨"과 "업로드 날짜"는 같은 값이다(글쓰기 화면에 관찰 일시 입력칸이 없다).
